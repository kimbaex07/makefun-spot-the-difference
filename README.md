A spot-the-difference game in the browser: three rounds of a hand-drawn café terrace scene with 6, 8, then 10 hidden changes, hints, a timer, and a score with a time bonus.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
